## Что реально делают столбцы

| Колонки | Фактическая роль | Влияние на баланс |
|---|---|---|
| A | Название и ключ текстур/ссылок | Ошибка имени ломает связи и изображения |
| B–D | Типы трёх снарядов | ОФ получает непробивной урон 20–30%; ОГОНЬ/FIRE — поток; ПТУР/ATGM — управляемый полёт |
| E–G | Номинальный урон | Каждый снаряд получает случайно 75–125% |
| H–O | Уровень, нация, связи ветки, цены, класс | Уровень задаёт пул ботов; класс влияет на башню, ИИ и скорость башни |
| P | HP | Прямая живучесть |
| Q | Перезарядка | Обычный цикл; `0` подменяется на 0,75 с игроку и 1,6 с боту, кроме огня |
| R | Задержка поворота | `1/R` град/с с жёстким пределом примерно 43–241 град/с; меньше лучше |
| S | Задержка движения | Скорость `7/S`, ограничена 90–280; для колёсных 120–360; меньше лучше |
| T–V | Пробитие каждого слота | Сравнивается со средней бронёй цели |
| W | Средняя броня | Один показатель на весь танк, углов и зон брони нет |
| X | Знаменатель броска, а не процент | При `пробитие ≥ броня`: шанс = `1 − 1/X`; иначе `1/X`. Для ОФ X утраивается. UI называет это процентом ошибочно |
| Y | Тип орудия | 1 обычное; 2 барабан с полной зарядкой; 3 дозарядка по одному. Значения 4–7 почти не меняют цикл сами по себе |
| Z | Снарядов за выстрел | Умножает разовый урон и расход БК; добавляет разлёт |
| AA | Магазин | Используется только для типов Y=2/3; задержка между выстрелами фиксирована 1 с |
| AB | Разброс | Случайное отклонение в пределах ±AB/2; меньше лучше |
| AC | Доступность | 0 будущий, 1 дерево, 2 прем/контейнер, 3 developer, 4 коллекционный |
| AD | Доп. способности | Парсится как пары кодов; `10` снимает штраф скорости в воде, `11` даёт +50% скорости вперёд на 10 с с перезарядкой 30 с, `12` уменьшает штраф воды с 45% до 20%, `13` включает осадный режим: скорость ×0,35, поворот ×0,6, разброс ×0,5 после 0,8 с неподвижности. Индекс баланса эти эффекты не учитывает |
| AE | Размер 1–5 | Масштаб 0,70/0,85/1,00/1,15/1,30; меняет коллизию и заметность цели |
| AF–AG | УВН вниз/вверх | Парсятся, но боевое наведение ими сейчас не ограничено; баланс-ценности нет |
| AH | Флаг детализации | Меняет оформление, на баланс не влияет |
| AI | Английское название | Меняет текст в английском интерфейсе, на баланс не влияет |
