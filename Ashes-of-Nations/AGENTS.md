# Правила проекта Ashes of Nations

## Cache busting

- При изменении `index.html`, `app.js`, `styles.css`, изображений или других подключаемых ресурсов обязательно обновлять числовой суффикс `?v=...`.
- Текущее значение версии кэша хранится в `app.js` в константе `CACHE_VERSION` и дублируется в подключениях ресурсов в `index.html` и URL фоновых изображений в `styles.css`.
- При следующем изменении обновлять `CACHE_VERSION` в формате `ГГГГММДД-ЧЧММСС` (например, `20260817-145318`) и синхронно менять это значение во всех статических `?v=` ссылках.
- Для динамических `fetch` допустим `Date.now()`, если запрос уже использует `cache: "no-store"`.
- Это правило относится ко всему проекту, включая `editor/`, `scenario-editor/`, `temporal-map-viewer/`, дополнительные HTML-страницы, локальные изображения, CSS, JavaScript и данные, загружаемые через `fetch`.

## Проверка

После изменений запускать:

```text
node --check app.js
npm run build
```

## Генерация флагов

- Все генерируемые флаги должны быть плоскими растровыми изображениями размером строго `1280×720` пикселей.
- Если флаг использовался в определённый исторический период, файл называть в формате `Страна (ГГГГ1–ГГГГ2).png`.
- Если один и тот же вариант флага использовался в нескольких периодах, файл называть в формате `Страна (ГГГГ1–ГГГГ2, ГГГГ3–ГГГГ4).png`.
- Для флага, используемого в настоящее время, использовать имя без дат: `Страна.png`.
